Aplikasi ini adalah aplikasi yang membantu orang2 untuk mengurangi waktu screen time
Gadget dengan cara membuat suatu sesi jeda dan bentuk notifikasi yang dapat di custom 
yang menghalangi layar pandang gadget sehingga orang bisa berhenti sementara menggunakan gadget, 
selain itu ada fitur jadwal aktivitas, alarm pengingat, dan recap penggunaan jeda.

## CARA MENJALANKAN APLIKASI

- masuk ke folder Project masuk ke terminal lalu jalankan perintah: flutter pub get
- jangan lupa untuk nyalakan mode developer di terminal dengan perintah: start ms-settings:developers
- setelah itu jalankan dengan perintah : flutter run
